## התגלית

הקונסטרוקציה 'אינו X אלא Y' היא חתימה סמנטית שהסטטיסטיקה השטחית לא ראתה:

| מקור | צפיפות ל-100 מילים |
|---|---|
| tarot pshat (AI) | 1.22 |
| tarot remez (AI) | 0.71 |
| wisdom answers (AI) | 0.64 |
| בראשית | 0.00 |
| תהלים | 0.00 |
| משלי | 0.00 |
| קהלת | 0.00 |
| משנה אבות | 0.00 |
| ביאליק | 0.00 |

אפס מוחלט אצל שישה מחברים אנושיים על פני 3000 שנה. עד 1.22 בתוכן AI.

## השכבה הנגדית (היפוך, לא מחיקה)

'אינו X אלא Y' הופך ל-'Y, לא X' — דקדוק תקין, משמעות נשמרת, התבנית נעלמת.

## דוגמה

לפני: "וזו אינה טיפשות אלא הקשבה למעלה"
אחרי: "וזו הקשבה למעלה, לא טיפשות"

## מה נשאר פתוח (כנות)

- tricola ואבסטרקציה עדיין לא מטופלים ב-counter (רק contrast)
- retention יורד ל-0.86 בפשט (מילים כמו 'אינה/אלא' יוצאות) — זה המחיר של שבירת תבנית
- ה-counter פועל ברמת המשפט; גיוון ברמת האוסף כולו דורש גם מגוון סכמה
